# [MIOpen] [ALMIOPEN-1898] RFC: MIOpen→hipDNN forwarding wrapper

Merged PR #7388 in [ROCm/rocm-libraries](https://github.com/ROCm/rocm-libraries/pull/7388).

**Author:** NolanHannaAMD
**Merged:** 2026-06-23

## Description

> This PR adds the RFC for a MIOpen→hipDNN forwarding wrapper (shim), which routes selected calls through hipDNN behind the existing MIOpen API. The goal is to let MIOpen consumers (PyTorch, TensorFlow, ONNX Runtime, JAX/XLA) start benefiting from hipDNN's engine ecosystem - performance work, fusion graphs, new architectures - without waiting on the non-trivial, badly-timed framework-side migration to a native hipDNN backend. The shim decouples the rollout of hipDNN-backed execution from any frame
