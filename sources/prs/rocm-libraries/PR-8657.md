# [stinkytofu] Exclude TensorLoad from EV_VGPR_VMEM_READ in InsertWaitAluPass

Merged PR #8657 in [ROCm/rocm-libraries](https://github.com/ROCm/rocm-libraries/pull/8657).

**Author:** darrenhsieh-amd
**Merged:** 2026-06-22

## Description

> TensorLoad (tensor_load_to_lds) instructions were being misclassified as EV_VGPR_VMEM_READ events in InsertWaitAluPass. This is incorrect: tensor loads move data directly from global memory into LDS without reading any VGPR source operands, so they do not participate in the expert mode2 hazard that s_wait_alu guards against.
