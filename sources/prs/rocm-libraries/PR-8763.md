# [CTest] ALMIOPEN-2219 Fix optional argument scoping in test categories

Merged PR #8763 in [ROCm/rocm-libraries](https://github.com/ROCm/rocm-libraries/pull/8763).

**Author:** BrianHarrisonAMD
**Merged:** 2026-06-24

## Description

> This PR fixes shared CTest category argument parsing so omitted optional parameters are not read through unset `ARGV<N>` variables. That prevents parent function positional args such as `EXPECT_TARGET` from leaking into `resource_group` and generating invalid `RESOURCE_GROUPS "1,EXPECT_TARGET:1"` properties for hipblaslt provider tests. This follows up on [PR #8188](https://github.com/ROCm/rocm-libraries/pull/8188), which added optional resource-group support.
