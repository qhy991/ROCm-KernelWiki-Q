# [CK TILE] Unification Work – Remove unification Flag structs in favor of new WarpGemmParams

Merged PR #8227 in [ROCm/rocm-libraries](https://github.com/ROCm/rocm-libraries/pull/8227).

**Author:** krithalith
**Merged:** 2026-06-26

## Description

> Recently, the way flags are sent down to the intrinsics was changed in CK Tile. At the point where the WarpGemm is invoked, an arbitrary number of template parameters can be passed, and these are passed down all the way to the lowest level intrinsics wrappers. Here `WarpGemmParamsParser<>` is used to extract flags for the intrinsics.
