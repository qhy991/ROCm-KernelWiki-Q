# [hipblaslt][tensilelite] Fix gfx1250 StreamK fixup flag coherence

Merged PR #8726 in [ROCm/rocm-libraries](https://github.com/ROCm/rocm-libraries/pull/8726).

**Author:** ThanHenderson
**Merged:** 2026-06-24

## Description

> The StreamK fixup flag is set by the producer and spun on by the consumer. PR #6837 fenced the partials on gfx1250 but left the flag under-fenced: the VMEM flag load has no glc, its global_inv ran only once after the spin (not per poll), and the flag store had no global_wb. A consumer could re-read a stale cached flag forever and deadlock. It only surfaces at large sizes, where StreamK runs enough cross-workgroup handshakes to hit the race.
