**Author:** TorreZuk
**Merged:** 2026-06-30

## Description

> This pull request removes AddressSanitizer (ASan)-specific code paths and conditional kernel launch configurations from the BLAS2 routines in rocBLAS. All kernel launch parameters now use production (non-ASan) values, and the related helper includes and logic have been eliminated. This simplifies the codebase and ensures consistent performance characteristics, regardless of whether ASan is enabled.
