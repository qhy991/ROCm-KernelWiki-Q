# [hipblaslt] Enable MBSK GSU on gfx1250

Merged PR #8008 in [ROCm/rocm-libraries](https://github.com/ROCm/rocm-libraries/pull/8008).

**Author:** StaceyLai
**Merged:** 2026-06-15

## Description

> Enable MBSK GSU on gfx1250. The existing MBSK code path emits several instructions that gfx1250's assembler/ISA does not accept (scalar atomic dec, `s_store_b32`, wave64-style SGPR-pair masks), and the GSU sync also needs a memory-pipeline drain to preserve XNACK-replay ordering. This PR makes MBSK functional and correct on gfx1250 while keeping all other architectures unchanged.
