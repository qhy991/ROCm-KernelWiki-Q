# [MIOpen] Disable CK grouped conv support for gfx1250

Merged PR #9050 in [ROCm/rocm-libraries](https://github.com/ROCm/rocm-libraries/pull/9050).

**Author:** SreecharanGundaboluAMD
**Merged:** 2026-07-07

## Description

> When running MIOpen on gfx1250, CK grouped convolution solvers were being selected despite having no compiled kernel instances for that architecture. This caused `HIP runtime error: invalid device function` crashes at runtime across hundreds of tests (GroupConv2D/3D forward/backward/weight-update, fused bias-activation, deterministic convolution) because the CK shared library `libMIOpenCKGroupedConv_gfx1250.so` was built and loaded, but its `is_applicable()` check only validates tensor shape/dty

- `projects/miopen/src/ck_impl/CMakeLists.txt` (+1/-1)
- `projects/miopen/src/include/miopen/solver/ck_utility_common.hpp` (+1/-1)
