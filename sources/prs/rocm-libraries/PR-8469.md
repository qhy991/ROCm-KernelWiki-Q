## Description

> The SDPA backward CPU reference accumulated dQ/dK/dV gradients directly in the output tensor type (e.g. BF16), truncating the running sum to a 7-bit mantissa at every iteration. With S=256 sequence positions this produced worse precision than the GPU ASM kernel, which uses FP32 accumulators (A32 path) and converts to BF16 once at the end via `dq_convert`.
