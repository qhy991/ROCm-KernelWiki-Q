# feat(rocblas): Add per-batch alpha stride support to scal

Merged PR #9108 in [ROCm/rocm-libraries](https://github.com/ROCm/rocm-libraries/pull/9108).

**Author:** Ryker0627
**Merged:** 2026-07-09

## Description

> Previously alpha was a single scalar applied to every problem in the batch. This PR lets callers pass a device-resident array of per-batch alpha values and index into it with a stride, matching the mechanism already used by gemv, ger, and axpy.
