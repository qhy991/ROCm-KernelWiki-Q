## Description

> This pull request adds support for building rocBLAS with only the hipBLASLt GEMM backend, without requiring Tensile. It introduces a new build option, ensures the codebase can be compiled and function with just hipBLASLt, and refactors conditional compilation and backend dispatch logic accordingly. Additionally, it improves logging and error handling for the new backend configuration.
