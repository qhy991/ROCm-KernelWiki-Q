# feat(hipblaslt-provider): Add FP8 OCP dequantize + GEMM support

Merged PR #8251 in [ROCm/rocm-libraries](https://github.com/ROCm/rocm-libraries/pull/8251).

**Author:** averinevg
**Merged:** 2026-06-29

## Description

> Adds OCP FP8 block-scaled matmul support to the hipBLASLt provider plugin. The plugin now recognizes a `BlockScaleDequantize → BlockScaleDequantize → Matmul` hipDNN graph and executes it as a single fused `hipblasLtMatmul` using hipBLASLt's `VEC32_UE8M0` scale mode. This enables `dequantize(FP8 OCP) → GEMM` with FP32/FP16/BF16 output on supported hardware.
