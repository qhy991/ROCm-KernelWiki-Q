# [ALMIOPEN-2092] Restructure MIOpen Jenkins pipeline to reduce Jenkinsfile size and support selective reruns

Merged PR #8415 in [ROCm/rocm-libraries](https://github.com/ROCm/rocm-libraries/pull/8415).

**Author:** SreecharanGundaboluAMD
**Merged:** 2026-06-17

## Description

> The MIOpen Jenkinsfile has grown significantly and now contains large inline `parallel{}` blocks that risk hitting the Java 64 KB per-method bytecode limit imposed by the Jenkins Declarative Pipeline engine. Additionally, when a CI build partially fails and users click "Restart from Stage", all sub-stages re-run unconditionally — including stages that already passed — wasting GPU node time and extending turnaround.
