# [stinkytofu] InsertWaitAluPass: converge mode0 at exit label so conditional in-region edges keep mode2

Merged PR #8476 in [ROCm/rocm-libraries](https://github.com/ROCm/rocm-libraries/pull/8476).

**Author:** darrenhsieh-amd
**Merged:** 2026-06-18

## Description

> The old region-exit logic dropped mode2 before a block's terminator whenever a successor left the region without checking for a conditional branch. But a conditional branch keeps one in-region edge (e.g. a loop back-edge), so disabling before it turns off mode2 on code that never left the region.
