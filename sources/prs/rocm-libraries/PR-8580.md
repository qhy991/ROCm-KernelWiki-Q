# [hipDNN] ALMIOPEN-2139 dnn-benchmarking: fuse batchnorm training/backward and layernorm with native ATen ops; generalize conv to 1D/2D/3D

Merged PR #8580 in [ROCm/rocm-libraries](https://github.com/ROCm/rocm-libraries/pull/8580).

**Author:** SamuelReeder
**Merged:** 2026-06-24

## Description

> Replaces hand-rolled reference implementations in dnn-benchmarking's PyTorch handler layer with fused ATen/built-in primitives and establishes one consistent dtype convention: every handler runs on the graph's tensors and dtypes (no implicit promotion of the data path), compute is assumed to be float32, and a non-float32 graph `compute_data_type` warns instead of failing. Also generalizes the convolution helpers from 2D-only to 1D/2D/3D.
