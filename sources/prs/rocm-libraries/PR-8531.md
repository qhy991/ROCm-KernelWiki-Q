# [CK_TILE] Use launched block size for GEMM occupancy query

Merged PR #8531 in [ROCm/rocm-libraries](https://github.com/ROCm/rocm-libraries/pull/8531).

**Author:** AviralGoelAMD
**Merged:** 2026-07-01

## Description

> The grouped, grouped-quant, and stream-k GEMM kernels were asking the occupancy query about `kBlockSize`, but on wave32 (gfx1250) we actually launch `kBlockSize/2`. So the occupancy came back too low and the persistent/stream-k grid ended up undersized.
