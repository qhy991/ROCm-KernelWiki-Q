# Compress .dat files with zlib to reduce installed package size

Merged PR #8294 in [ROCm/rocm-libraries](https://github.com/ROCm/rocm-libraries/pull/8294).

**Author:** talumbau
**Merged:** 2026-06-24

## Description

> Compress TensileLite `.dat` files (msgpack solution-selection catalogs) with zlib at build time, shrinking the hipBLASLt installed package dramatically. For gfx942, `.dat` files go from **2.21 GB → 0.15 GB** (93% reduction, ~14:1 ratio). Compressed files use the `.dat.zlib` extension to accurately reflect the zlib (RFC 1950) format.
