# [rocsparse] Preserve pivot sign/phase in ILU0 numeric boost

Merged PR #8084 in [ROCm/rocm-libraries](https://github.com/ROCm/rocm-libraries/pull/8084).

**Author:** kliegeois
**Merged:** 2026-06-30

## Description

> The csrilu0/bsrilu0 "numeric boost" feature replaced a near-zero pivot with the user-supplied boost value while ignoring the sign (real) or phase (complex) of the original pivot. This inflates the factorization residual. This PR makes the boost sign/phase-preserving across all four value types, fixes the host reference accordingly, and extends test coverage.
