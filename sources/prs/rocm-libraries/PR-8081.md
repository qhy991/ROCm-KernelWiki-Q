# [MIOpen] Add gfx950 SystemDB for MI350X/MI355X

Merged PR #8081 in [ROCm/rocm-libraries](https://github.com/ROCm/rocm-libraries/pull/8081).

**Author:** jdcampbe
**Merged:** 2026-06-22

## Description

> MIOpen ships per-arch find/perf databases under `src/kernels/`, but no gfx950 SystemDB was packaged. Without it, gfx950 runs fall back to runtime tuning on every invocation. MI350X and MI355X both expose 256 CUs, so a single `gfx950100` basename serves both per `Handle::GetDbBasename()` (hex(256) = `0x100`, and the `_<cu>` suffix is omitted for >64 CU).
