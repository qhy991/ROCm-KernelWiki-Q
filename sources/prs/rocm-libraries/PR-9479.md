# fix(hipblaslt): Fix rotating buffer and flush under adaptive timing

Merged PR #9479 in [ROCm/rocm-libraries](https://github.com/ROCm/rocm-libraries/pull/9479).

**Author:** caio96
**Merged:** 2026-07-17

## Description

> `hipblaslt-bench`/`hipblaslt-sequence`'s adaptive timing mode (`--adaptive`) needs its rotating-buffer sizing and reported statistics to be internally consistent and to actually reflect how iterations run and get measured. This PR fixes rotating-buffer under-provisioning under `--adaptive`, adds visibility into the resolved adaptive configuration, and corrects flush-overhead accounting so every timing statistic in a benchmark row agrees with the others.
