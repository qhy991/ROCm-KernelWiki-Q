# Remove OpenCL backend from MIOpen

Merged PR #8433 in [ROCm/rocm-libraries](https://github.com/ROCm/rocm-libraries/pull/8433).

**Author:** iq136boy
**Merged:** 2026-07-08

## Description

> MIOpen is retiring its OpenCL backend. All OCL solvers have already been converted to HIP in prior PRs (#6859, #7281, #7637, #7047, #7347, #7575). This PR comprehensively removes the OpenCL backend — conditional compilation blocks, OCL-only source files, OpenCL compiler infrastructure, and all remaining OCL residue — keeping only the HIP code paths. This is dead-code removal with no behavior changes for HIP builds.
