# [fft mpi workers] Use reference_fft_data in MPI tests

Merged PR #7225 in [ROCm/rocm-libraries](https://github.com/ROCm/rocm-libraries/pull/7225).

**Author:** regan-amd
**Merged:** 2026-07-08

## Description

> For accuracy tests, MPI workers defaults to using in-place FFTW plans with unmodified strides (copied from the test parameters), albeit those strides are not necessarily satisfying the [FFTW3 requirements for real in-place transforms](https://www.fftw.org/fftw3_doc/Real_002ddata-DFT-Array-Format.html). While this _may_ produce correct results, it is not guaranteed and this usage is not reliable for producing comparative results, generally speaking.
