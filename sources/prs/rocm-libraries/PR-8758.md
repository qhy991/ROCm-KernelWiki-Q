## Description

> LSTM backward weights produced wrong bias gradients (~30% too small) on gfx1250 (mi450/RDNA4), causing `test_variable_sequence_cuda_float32` to fail in PyTorch. The bug only manifested with variable-length (packed) sequences and was gfx1250-specific — gfx942 (MI300X) with identical inputs passed.
