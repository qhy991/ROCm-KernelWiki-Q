# rocfft: add internal test suite for library-side unit tests

Merged PR #8446 in [ROCm/rocm-libraries](https://github.com/ROCm/rocm-libraries/pull/8446).

**Author:** Abuudiii
**Merged:** 2026-06-25

## Description

> rocFFT has no clean way to unit-test internal code that isn't part of the public API (e.g. `function_pool`). The only option was to link internal pieces into the public test binary behind `#ifdef` guards, which silently dropped the test in builds where those pieces weren't available. This PR adds a dedicated home for internal tests so they always build and run, can be run as part of the build, can be filtered by CI, and so adding more is trivial.
