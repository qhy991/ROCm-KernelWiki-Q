## Description

> Move the `bsrilu0_graph_test` cases (the `graph_test: true` variants of `bsrilu0`) to `category: known_bug`. On memory-constrained GPUs such as the **gfx110X** family (gfx1100/gfx1101/gfx1102/gfx1103), these cases fail with `hipErrorOutOfMemory` in `hipGraphLaunch`, which repeatedly blocks `rocm-libraries` → `ROCm/TheRock` bump PRs.
