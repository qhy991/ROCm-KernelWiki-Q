# [hipDNN] Read default flatc version from file

## Description

> Both CMake and the run_flatc.py script require knowledge of the default flatbuffer version. Currently they are kept in sync by the run_flatc.py script using a regular expression to find the line in CMake where the version is set, however this was recently broken when an intermediate `_HIPDNN_DEFAULT_FLATBUFFERS_VERSION` was introduced.
