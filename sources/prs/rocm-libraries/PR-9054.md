# fix(stinkytofu): use portable getenv wrapper in stinkytofu-opt

Merged PR #9054 in [ROCm/rocm-libraries](https://github.com/ROCm/rocm-libraries/pull/9054).

**Author:** KKyang
**Merged:** 2026-07-13

## Description

> Building `stinkytofu-opt` with `amdclang++` against the MSVC CRT headers emits a `-Wdeprecated-declarations` warning for the bare `std::getenv` call in `InsertClusterBarrierPass`'s option lambda (`stinkytofu-opt.hpp`). It's currently tolerated only via the blanket `-Wno-error=deprecated-declarations` exemption in `shared/stinkytofu/CMakeLists.txt`; this fixes the actual call site instead.

## Changed Files

- `shared/stinkytofu/tools/stinkytofu-opt/stinkytofu-opt.hpp` (+9/-0)
