# feat(tensilelite): Enable dynamic-queue and hybrid StreamK on gfx1250

Merged PR #9074 in [ROCm/rocm-libraries](https://github.com/ROCm/rocm-libraries/pull/9074).

**Author:** ThanHenderson
**Merged:** 2026-07-13

## Description

> gfx12/gfx1250 dropped scalar memory atomics (`s_atomic_inc`) that StreamK's dynamic work-queue used to fetch its counter, blocking dynamic (SK4) and hybrid (SK5) StreamK. This patch fetches the counter with a returning vector atomic instead to enable both on gfx1250.
