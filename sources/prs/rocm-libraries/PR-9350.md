**Merged:** 2026-07-16

## Description

> Adds a developer tooling script, `projects/hipdnn/scripts/bump-hipdnn-versions.sh`, that reports and optionally applies per-component hipDNN `version.json` bumps. For each component it compares source drift since the last `release/therock-*` branch was cut and flags whether the component still needs a version bump, with opt-in `--apply` and per-level (`--major/--minor/--patch`) control.
