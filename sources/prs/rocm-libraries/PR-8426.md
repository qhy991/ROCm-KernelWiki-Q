# [MIOpen] Fix softmax kernel NaN failure when beta=0 (ROCM-26026)

Merged PR #8426 in [ROCm/rocm-libraries](https://github.com/ROCm/rocm-libraries/pull/8426).

**Author:** SreecharanGundaboluAMD
**Merged:** 2026-06-17

## Description

> When `beta=0` is passed to the MIOpen softmax kernel, the output buffer (`y` forward, `dx` backward) may contain uninitialized memory or NaN. The kernel was unconditionally reading and scaling these buffers by `beta`, which produces NaN under IEEE 754 semantics (`NaN * 0.0 == NaN`), poisoning the result even though `beta=0` means the buffer should be ignored entirely. This fixes ROCM-26026 and adds a regression gtest to catch any future reintroduction.
