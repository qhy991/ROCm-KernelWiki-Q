## Description

> This pull request updates several GEMM test cases to ensure that the `alpha` parameter is explicitly passed to the tested functions even when `K == 0`. Previously, `nullptr` was allowed for `alpha` in these cases, but the new hipblaslt may dereference which is allowed in legacy blas.
