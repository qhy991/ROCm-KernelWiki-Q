## Description

> This PR fixes [issue #8530](https://github.com/ROCm/rocm-libraries/issues/8530) by removing ambiguous hipDNN frontend dimension inference for convolution backward data `dx` and backward weight `dw`. The issue is that forward convolution spatial sizes use floor division, so `dx` and `dw` cannot always be reconstructed uniquely from `dy`, weights/input tensors, and convolution parameters; callers must now provide the original forward input/weight-gradient dimensions explicitly.
