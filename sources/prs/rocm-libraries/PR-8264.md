# feat(hipdnn): Autotune

Merged PR #8264 in [ROCm/rocm-libraries](https://github.com/ROCm/rocm-libraries/pull/8264).

**Author:** CMiservaAMD
**Merged:** 2026-06-30

## Description

> Implements the hipDNN autotune feature per [RFC 0013](projects/hipdnn/docs/rfcs/0013_Autotune.md), covering both the cuDNN-compat surface (compiled-plan autotuning, indexed plan APIs, `build_plans(policy)`) and the hipDNN-extended surface (plan-spec sweeps, engine variants, exhaustive priming, custom ranking, and result persistence). Autotune is opt-in via explicit `autotune()` calls and does not change existing default dispatch.
