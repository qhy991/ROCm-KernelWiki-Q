# feat(hipdnn): parse-once PyTorch ref+ stalled-queue A/B timing (ALMIOPEN-2153)

Merged PR #8737 in [ROCm/rocm-libraries](https://github.com/ROCm/rocm-libraries/pull/8737).

**Author:** SamuelReeder
**Merged:** 2026-07-06

## Description

> Removes host-side timing inflation in the dnn-benchmarking A/B harness (hipDNN-engine vs PyTorch-reference) on identical MIOpen kernels. Two core fixes: the PyTorch reference graph is compiled **once** into replayable per-op closures (no re-walking of graph JSON per iteration), and **both** executors measure each iteration through a **stalled-queue staged region** so the GPU event span is gap-free and host parse/launch cost never lands inside it. Timings are renamed from `e2e` to `host + kernel`
