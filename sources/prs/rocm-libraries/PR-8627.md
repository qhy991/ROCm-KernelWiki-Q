# [hipblaslt][tensile] strip sramecc from helper-kernel code-object filename

Merged PR #8627 in [ROCm/rocm-libraries](https://github.com/ROCm/rocm-libraries/pull/8627).

**Author:** davidd-amd
**Merged:** 2026-06-19

## Description

> The per-arch source/helper code objects (`Kernels.so-000-<arch>.hsaco`, built by `TensileCreateLibrary`) were named from the full bundler target via `re.sub(":", "-", rawArch)`. For a cooked target like `gfx942:sramecc+:xnack+` this produced `Kernels.so-000-gfx942-sramecc+-xnack+.hsaco`, which the runtime loader can never find. This PR strips the `sramecc` (and any non-`xnack`) feature from the filename so the producer matches the runtime probe, fixing the source/helper-kernel load failures seen
