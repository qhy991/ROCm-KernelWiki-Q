# [ALMIOPEN-2130] [MIOpen] Add gfx1250 support to gtests

Merged PR #8526 in [ROCm/rocm-libraries](https://github.com/ROCm/rocm-libraries/pull/8526).

**Author:** SreecharanGundaboluAMD
**Merged:** 2026-06-18

## Description

> This PR extends MIOpen's batch normalization kernel infrastructure and GTest framework to support the gfx1250 GPU architecture (gfx125X family). Without this support, gfx1250 devices fall through to incorrect code paths (e.g., enabling AMDGCN instructions unsupported on this target) and cannot be recognized or tested via the GTest harness.
