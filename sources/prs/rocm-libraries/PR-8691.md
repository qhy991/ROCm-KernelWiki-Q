# [hipDNN] ALMIOPEN-2193 Fix superbuild logging test flakiness

Merged PR #8691 in [ROCm/rocm-libraries](https://github.com/ROCm/rocm-libraries/pull/8691).

**Author:** BrianHarrisonAMD
**Merged:** 2026-06-24

## Description

> This PR isolates hipDNN backend user logging tests from provider plugin discovery in superbuild configurations. The logging fixture creates hipDNN handles only to generate log messages, so it now forces empty absolute engine and heuristic plugin paths during each test and restores default plugin loading in teardown. It also adds public backend coverage for the empty/null heuristic plugin-path API behavior that the fixture relies on.
