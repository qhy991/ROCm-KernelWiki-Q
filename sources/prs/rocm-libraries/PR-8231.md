# test(hipblaslt): Add 32-bit/size_t overflow test coverage for large-size kernels

Merged PR #8231 in [ROCm/rocm-libraries](https://github.com/ROCm/rocm-libraries/pull/8231).

**Author:** tony-davis
**Merged:** 2026-07-07

## Description

> Adds client-side regression coverage for the class of 32-bit / `size_t` index and byte-offset overflows in the TensileLite addressing path that occur when a matmul operand (or the output) has a very large leading dimension or batch stride. Compute (M×N×K) stays moderate while a leading dimension / batch stride is inflated so the element index and the byte offset (index × bytes-per-element) cross 2^31. Full `unit_check` catches both hard memory faults and **silent result corruption**.
