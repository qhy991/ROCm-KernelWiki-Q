# [hipDNN] Add RFC 0015: Per-Graph Engine Support Claims

Merged PR #8235 in [ROCm/rocm-libraries](https://github.com/ROCm/rocm-libraries/pull/8235).

**Author:** adickin-amd
**Merged:** 2026-06-16

## Description

> Adds [RFC 0015](projects/hipdnn/docs/rfcs/0015_EngineSupportClaims.md), proposing a per-graph engine-support gate layered on the golden reference framework ([RFC 0011](projects/hipdnn/docs/rfcs/0011_GoldenReferenceValidation.md)). Each golden bundle gains a machine-owned `{Name}.support.json` recording, per `(engine, arch, platform)`, whether the engine is expected to support that exact graph; enforcement replaces RFC 0011's silent `unsupported → GTEST_SKIP` with a claim-broken **FAIL**, closing
