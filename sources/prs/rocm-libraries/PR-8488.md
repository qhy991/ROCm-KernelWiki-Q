# [hipblaslt] Fix MBSK GSU>1 synchronizer race on gfx1250

Merged PR #8488 in [ROCm/rocm-libraries](https://github.com/ROCm/rocm-libraries/pull/8488).

**Author:** StaceyLai
**Merged:** 2026-06-17

## Description

> The MBSK last-WG reduction handshake used mismatched memory ops on the shared synchronizer slot: the producer WG signals with flat_atomic_dec_u32 while the reducer WG polled with buffer_load_b32 and cleared with buffer_store_b32. On gfx1250 a plain load/store is not ordered against an atomic RMW from another CU, so the reducer's read+reset races with the producer's dec: the slot is left at 1 (hanging the next launch that reuses it) or the spin never observes the dec (immediate hang).
