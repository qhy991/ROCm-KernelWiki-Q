# [hipDNN] ALMIOPEN-2082 Enable LSE/stats output for SDPA forward golden data

Merged PR #8522 in [ROCm/rocm-libraries](https://github.com/ROCm/rocm-libraries/pull/8522).

**Author:** AnaghaRaoAMD
**Merged:** 2026-06-19

## Description

> The SDPA forward kernel supports an optional LSE (Log-Sum-Exp) statistics output tensor, but the golden data generator ignores the `--stats` flag and the C++ plan builder rejects any graph that requests it. This blocks backward golden data generation because the backward kernel requires LSE as an input tensor. This PR wires up LSE output end-to-end across the Python generator, provider C++, CPU reference executor, and integration tests.
