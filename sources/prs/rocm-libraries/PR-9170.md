# test(hipblaslt): raise standard-tier ctest timeout from 30m to 1h

Merged PR #9170 in [ROCm/rocm-libraries](https://github.com/ROCm/rocm-libraries/pull/9170).

**Author:** tony-davis
**Merged:** 2026-07-08

## Description

> The `standard` test tier for `hipblaslt-test` uses an 1800s (30 min) per-test CTest timeout, and the suite runs right at that ceiling on gfx94X-dcgpu, so shards intermittently time out and need re-runs. For example, in #8984 shard 4 of 6 timed out on its first attempt (`hipblaslt-test_standard_suite ....***Timeout 1801.29 sec`, exit code 8) and then passed on re-run at ~1667s, roughly 2 minutes under the cap. See #9169.
