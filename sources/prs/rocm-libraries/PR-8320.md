# [CK DSL] gfx950 GEMM: arch-resolve compv4 schedule hints (~+2%)

Merged PR #8320 in [ROCm/rocm-libraries](https://github.com/ROCm/rocm-libraries/pull/8320).

**Author:** AviralGoelAMD
**Merged:** 2026-06-18

## Description

> On gfx950 the compv4/compv3 GEMM pipeline's `sched_group_barrier` HotLoop + per-cluster `s_setprio`/`sched_barrier(0)` fences (from the CK Tile C++) *over-constrain* comgr's backend scheduler. Removing them is a measured, correctness-preserving uplift. This adds a `TraitSpec.emit_sched_hints` knob, arch-resolved so gfx950 takes the win by default while every other arch stays byte-identical.
