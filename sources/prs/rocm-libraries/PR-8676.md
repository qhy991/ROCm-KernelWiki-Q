## Description

> Documents the snapshot-update governance for the TensileLite **characterization** suite (the 99 `.ambr` goldens landed by #7989) and makes a golden mismatch self-explanatory at failure time. Goal: when a behavior change trips a golden, the author updates only the affected node and reviews the diff — never a blanket `pytest --snapshot-update` that silently rewrites all 99 and destroys the net.
