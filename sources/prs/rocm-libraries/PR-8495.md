# [hipDNN] Fix HIPDNN_ENABLE_SDPA flag being ignored when set by TheRock (ALMIOPEN-2120)

Merged PR #8495 in [ROCm/rocm-libraries](https://github.com/ROCm/rocm-libraries/pull/8495).

**Author:** DarylHawkinsAMD
**Merged:** 2026-06-17

## Description

> hipDNN's top-level CMake evaluated the `HIPDNN_ENABLE_SDPA` option and `add_compile_definitions(HIPDNN_ENABLE_SDPA)` *before* `project()`. A value injected by an embedding build system via `CMAKE_PROJECT_TOP_LEVEL_INCLUDES` — which CMake only processes during the `project()` call — therefore arrived too late: `option()` fell back to its `OFF` default and the compile definition was skipped, so SDPA stayed disabled even when the flag was set on.
