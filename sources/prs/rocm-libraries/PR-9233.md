# gfx950 D256 BF16 Prefill Fast-Path Landing

## Summary

This PR is the upstream `develop` landing point for a gfx950 D256 BF16
attention feature branch. It changes production routing for the targeted
cohort to a 32x32 transposed path and enables FA3-style softmax-MFMA
interleaving with mode 2 and four groups. It also carries the slab-granularity
K-LDS padding introduced on the feature branch by PR #9260.

The routing change gates the launch geometry selectors and code-generation
flags together so the builder spec, cache key, and launch metadata agree.
Non-D256 shapes remain outside the route.

## Source-Reported Performance

The PR reports direct-launch results on MI355X/gfx950 for Qwen3-Next-style
batch-1, causal, D256 BF16 prefill with GQA 16/2:

| Sequence / paged block size | rocKE | AOTriton | Relative |
|---|---:|---:|---:|
| S4096 / 64 | 440.0 TFLOPS | 226.7 TFLOPS | 1.94x |
| S8192 / 64 | 556.5 TFLOPS | 403.5 TFLOPS | 1.38x |
| S4096 / 16 | 356.2 TFLOPS | 228.0 TFLOPS | 1.56x |
| S8192 / 16 | 442.4 TFLOPS | 401.9 TFLOPS | 1.10x |

All four source-reported shapes passed against an FP32 paged-attention
reference with maximum absolute error `0.015625`.

## Scope and Limits

The evidence covers the batch-1 long-prefill ticket workload. The PR notes
that the S8192 advantage narrows or reverses at high aggregate batch and that
true batch 64 at S8192 exceeds a pre-existing `grid.y` limit. These gfx950
results cannot be reproduced on the available gfx942 node.
