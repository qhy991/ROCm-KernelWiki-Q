# Remove forced OpenBLAS/OpenMP thread env from client test categories

Merged PR #8621 in [ROCm/rocm-libraries](https://github.com/ROCm/rocm-libraries/pull/8621).

**Author:** tony-davis
**Merged:** 2026-06-24

## Description

> Move the OpenBLAS/OpenMP CPU thread caps for the rocBLAS, hipBLAS, and hipSPARSELt client test suites out of the CTest `ENVIRONMENT` property and onto the test container. Removing the `environment:` block from each `test_categories.yaml` lets the container-exported `OPENBLAS_NUM_THREADS` / `OMP_NUM_THREADS` flow through instead of being overridden per-suite.

## Changed Files

- `projects/hipblas/clients/gtest/test_categories.yaml` (+0/-3)
- `projects/hipsparselt/clients/test/test_categories.yaml` (+0/-3)
- `projects/rocblas/clients/gtest/test_categories.yaml` (+0/-3)
