# [rocBLAS] Implement batched GER/GERU with per-batch alpha coefficients

Merged PR #8300 in [ROCm/rocm-libraries](https://github.com/ROCm/rocm-libraries/pull/8300).

**Author:** Ryker0627
**Merged:** 2026-06-15

## Description

> QMCPACK's performance-critical path (OLCF-6) relies on small, pointer-array batched GER-family rank-1 updates where each batch index carries its own scalar coefficient alpha[batch] resident on device. Standard rocBLAS batched GER/GERU APIs only expose a single alpha shared across the entire batch.
