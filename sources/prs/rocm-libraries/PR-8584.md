# [hipDNN] ALMIOPEN-1972 Rename golden_reference_data to integration_test_bundles

Merged PR #8584 in [ROCm/rocm-libraries](https://github.com/ROCm/rocm-libraries/pull/8584).

**Author:** adickin-amd
**Merged:** 2026-06-18

## Description

> Renames `dnn-providers/integration-tests/golden_reference_data/` to `integration_test_bundles/` and updates every reference across CMake, C++, tooling, and documentation. The new name better reflects the directory's purpose — it holds self-contained test bundles for the integration test suite, not a dataset that is always required. Bundles are now explicitly optional: tests run without them using `--verification-mode gpu` or `--verification-mode cpu`.
