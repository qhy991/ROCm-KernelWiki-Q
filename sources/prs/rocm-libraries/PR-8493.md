# [hipDNN] ALMIOPEN-2117 Hard engine selection + selected-engine read-back for dnn-benchmarking

Merged PR #8493 in [ROCm/rocm-libraries](https://github.com/ROCm/rocm-libraries/pull/8493).

**Author:** SamuelReeder
**Merged:** 2026-06-17

## Description

> Fixes a silent-fallback bug in the `dnn-benchmarking` tool: a forced/preferred engine is a *soft* request in hipDNN, so when the forced engine is not applicable to a graph the frontend silently runs the top-ranked engine instead while the tool still labels the timing row with the requested engine — fabricating comparison rows where several "different" forced engines are all secretly the same fallback. This PR adds deterministic hard engine selection plus a selected-engine read-back to the hipDNN
