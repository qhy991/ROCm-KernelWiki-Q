# [hipDNN] ALMIOPEN-1896 Extend autotune config op matching

Merged PR #8562 in [ROCm/rocm-libraries](https://github.com/ROCm/rocm-libraries/pull/8562).

**Author:** BrianHarrisonAMD
**Merged:** 2026-06-19

## Description

> This PR extends hipDNN autotune config persistence so frontend-written config entries can be matched by the backend across supported primary operations, not just convolution. The final format is versioned: missing `version` is treated as the legacy positional format for reads, while new writes emit the current named-tensor format only.
