# feat(rocblas): add per-batch alpha/beta stride to remaining Level 2 functions

Merged PR #9425 in [ROCm/rocm-libraries](https://github.com/ROCm/rocm-libraries/pull/9425).

**Author:** Ryker0627
**Merged:** 2026-07-16

## Description

> Extends the per-batch scalar mechanism already used by gemv and ger to the remaining Level 2 batched/strided-batched functions whose internal API already accepts it (hemv, symv, sbmv, spmv, syr), so callers can pass device-resident per-batch alpha/beta arrays instead of a single shared scalar.
