# [stinkytofu] Throttle tensor_load_to_lds with a bounded in-flight credit pool

Merged PR #8345 in [ROCm/rocm-libraries](https://github.com/ROCm/rocm-libraries/pull/8345).

**Author:** KKyang
**Merged:** 2026-06-15

## Description

> - Each outstanding tensor load holds a credit until its modeled drain latency decays to 0 (decayed in `advanceTime`, the same guess-based cycle model LLVM uses for buffered `ProcResource`s / `ReservedCycles`). A new tensor load is gated while the pool is full.
