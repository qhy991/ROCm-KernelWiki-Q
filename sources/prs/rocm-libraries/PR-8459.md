# [hipDNN] Co-locate Python bindings extension with backend

Merged PR #8459 in [ROCm/rocm-libraries](https://github.com/ROCm/rocm-libraries/pull/8459).

**Author:** tvy-amd
**Merged:** 2026-06-17

## Description

> Install the `hipdnn_frontend_python` extension co-located with `libhipdnn_backend` (`lib/` on Linux, `bin/` on Windows) and set `INSTALL_RPATH=$ORIGIN`, so a bare `dlopen` of the extension resolves the backend as a sibling. This lets `rocm-sdk`'s `testSharedLibrariesLoad` (the `devel_test` variant, which does a raw `ctypes.CDLL`) load the extension instead of failing with `libhipdnn_backend.so: cannot open shared object file`.
