## Description

> Many input yaml files contain stale, incorrectly placed, or wrongly typed (most often int instead of bool, or vice versa). This PRs add validation for them and will error out on any incorrect values. It remains disabled in this PR and will be enabled in #8328 because the yaml-diff associated with enabling it is very large.
