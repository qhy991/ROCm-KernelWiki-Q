# [rocsparse] Debug memory

Merged PR #6844 in [ROCm/rocm-libraries](https://github.com/ROCm/rocm-libraries/pull/6844).

**Author:** YvanMokwinski
**Merged:** 2026-06-16

## Description

> This PR adds a runtime framework for debugging and verifying HIP API usage within rocSPARSE. It intercepts every HIP memory management and synchronization call, records an API call history per invocation, and exposes a public C API to query     this information. A client-side test infrastructure validates observed behavior against expected synchronicity contracts.
