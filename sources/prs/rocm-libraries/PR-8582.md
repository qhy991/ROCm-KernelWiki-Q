# [stinkytofu] Freeze tensor waitcnt dataflow across loop back-edges

Merged PR #8582 in [ROCm/rocm-libraries](https://github.com/ROCm/rocm-libraries/pull/8582).

**Author:** pschang-phy
**Merged:** 2026-06-18

## Description

> Avoid unnecessary loop-header `s_wait_tensorcnt(0)` emissions caused by loop-carried tensor token state. In loop CFGs such as `label_LoopBeginL -> ... -> label_LoopBeginL`, the tensor token state from a back-edge can make the header wait on tensor work from an earlier iteration even when that wait is not required.
