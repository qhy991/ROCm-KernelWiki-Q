# feat(hipblaslt): Adding ULP measurements to hipblaslt-bench

Merged PR #8979 in [ROCm/rocm-libraries](https://github.com/ROCm/rocm-libraries/pull/8979).

**Author:** smalekta
**Merged:** 2026-07-09

## Description

> Our current accuracy checks in hipblaslt-bench are norm-based (norm_error, atol/rtol). These metrics tell us if a result is close overall, but they could hide a few very wrong values and their meaning changes with the size of the numbers. ULP (units in the last place) measures error as the number of floating-point values between the computed and reference result, so one number means the same thing at any magnitude and catches errors down to the last bit. This makes it good at finding subtle bugs
