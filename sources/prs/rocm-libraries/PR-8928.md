# feat(rocke): add rocke-client skeleton

Merged PR #8928 in [ROCm/rocm-libraries](https://github.com/ROCm/rocm-libraries/pull/8928).

**Author:** BrianHarrisonAMD
**Merged:** 2026-06-30

## Description

> Adds a skeleton `rocKEclient` project under `dnn-providers/hip-kernel-provider/rocKE-client`, gated by the rocKE provider flag from [PR #8864](https://github.com/ROCm/rocm-libraries/pull/8864). When enabled, the project builds and installs `librocKEclient.so` beside the existing hip-kernel-provider plugin so hipDNN can load it, while the skeleton reports no applicable engines yet. This is the start of the rocKE client library, and will be directly exposing the hipDNN provider API to start with.
