# [hipDNN] ALMIOPEN-2101 Add libsqlite3-dev to Ubuntu 24 Dockerfile

Merged PR #8444 in [ROCm/rocm-libraries](https://github.com/ROCm/rocm-libraries/pull/8444).

**Author:** SamuelReeder
**Merged:** 2026-06-16

## Description

> This PR unblocks the hipDNN Ubuntu 24 Docker image build by installing the sqlite3 development headers required by `rocprofiler-sdk` SQL output sources. The immediate trigger is [ROCm/rocm-systems#6664](https://github.com/ROCm/rocm-systems/pull/6664), which stopped linking `rocprofiler-sdk-output-library` to `rocprofiler-sdk::rocprofiler-sdk-sqlite3` to avoid mixed SQLite libraries in the rocpd Python extension; that also removed the SQLite include path for sources that still `#include <sqlite3.
