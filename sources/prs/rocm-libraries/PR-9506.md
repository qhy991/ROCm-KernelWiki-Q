## Description

> The build(stop_after=...) refactor (#9127) moved pipeline orchestration into build(); pass methods no longer self-run their prerequisites and the @pipeline_pass decorator is registration-only. The initD preloop tests added by #8615 still called sched.emit() directly, leaving self._partitions is None and raising "TypeError: 'NoneType' object is not iterable" on develop unit CI.
