## Description

> Add packed 8-wide (pk8) FP8 conversion instructions for gfx1250, converting 8 F32 values to 8 FP8/BF8 values in a single instruction. This reduces instruction count in global write and enables further optimizations such as fusing alpha multiplication into the conversion.
