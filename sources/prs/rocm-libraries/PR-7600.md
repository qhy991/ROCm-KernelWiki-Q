**Author:** tvy-amd
**Merged:** 2026-06-18

## Description

> Add a pytest suite for the hipDNN Python bindings and wire it into TheRock CI so it runs on GPU hardware. The suite covers the tensor and graph APIs, device-buffer/memory round-trips, engine-id overloads, and end-to-end convolution (fprop/dgrad/wgrad) execution, plus build-stage coverage for matmul and pointwise.
