**Author:** SamuelReeder
**Merged:** 2026-06-17

## Description

> Extends the dnn-benchmarking PyTorch reference provider to cover more hipDNN graph operations, giving those graphs a correctness reference and a same-device timed PyTorch baseline during benchmarking. New operations are validated against PyTorch built-ins/autograd on CPU PyTorch and exercised end-to-end on GPU ROCm PyTorch.
