# [dnn-benchmarking] Add CUDA support to the PyTorch backend

Merged PR #8280 in [ROCm/rocm-libraries](https://github.com/ROCm/rocm-libraries/pull/8280).

**Author:** SamuelReeder
**Merged:** 2026-06-15

## Description

> Adds a CUDA path to the dnn-benchmarking `--backend pytorch` executor so an NVIDIA host (no ROCm/hipDNN) can benchmark the same graph shapes through PyTorch and emit a `SuiteResult` JSON comparable to a ROCm run, for offline ROCm-vs-CUDA comparison. The tool stays importable without `hipdnn_frontend` (the HIP timer now imports it lazily), gains a `torch.cuda`-event timing backend alongside HIP events, and `setup.sh --torch-mode cuda` installs a CUDA torch wheel while skipping all ROCm setup.
