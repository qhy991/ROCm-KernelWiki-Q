# [MIOpen] Feature-engineered 2D AI heuristics (Tunanet + KTN candidate selection) for gfx942 & gfx950

Merged PR #7109 in [ROCm/rocm-libraries](https://github.com/ROCm/rocm-libraries/pull/7109).

**Author:** amd-ahyttine
**Merged:** 2026-06-19

## Description

> MIOpen's 2D AI heuristics previously fed raw convolution and kernel-config parameters directly into the fdeep models. Training showed that explicit, stateless feature engineering improves both solver selection (Tunanet) and kernel-config ranking (KTN candidate selection) for grouped implicit-GEMM convolutions. This PR ports that feature engineering into the C++ inference path so training and inference agree, and extends the engineered path from gfx950 to gfx942 (MI300).
