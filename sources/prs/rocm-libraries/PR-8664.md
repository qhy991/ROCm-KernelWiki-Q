# [hipBLASLt] Add intermediate K grid points for gfx1151

Merged PR #8664 in [ROCm/rocm-libraries](https://github.com/ROCm/rocm-libraries/pull/8664).

**Author:** serged-amd
**Merged:** 2026-06-26

## Description

> 3072xNx1024 GEMM was only achieving ~11TFLOP/s due to poor solution selection.  The distance heuristic favored K=32 grid points for these MxN points which is not optimal.  After auditing the entire grid it was found that other MxN shapes also had a gap between small K(=32) and large K(>2048).  This PR aims to add intermediate K entries for all those MxN points.
