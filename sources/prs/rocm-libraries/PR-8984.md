## Description

> This pull request introduces support for running CTest category suites using a project-specific rtest Python driver instead of invoking the gtest binary directly. It also adds the ability to specify a `test_yaml` file per test category, which is injected into test commands, and improves flexibility in how CI labels are passed to tests. Documentation and validation logic have been updated to reflect these new features.
