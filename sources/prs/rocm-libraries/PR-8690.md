## Description

> This PR updates [RFC 0011](projects/hipdnn/docs/rfcs/0011_GoldenReferenceValidation.md) to include the compressed template-sweep bundle strategy alongside the original single-graph bundle format. The RFC now describes how shared-topology bundle cases use `graph.template.json`, `sweep.json`, per-case tensor metadata, stable case ids, and per-case golden tensor directories.
