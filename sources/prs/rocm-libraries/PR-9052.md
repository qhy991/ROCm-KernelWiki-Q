# fix(hipblaslt): tolerate non-mbcs bytes in vcvarsall.bat output

Merged PR #9052 in [ROCm/rocm-libraries](https://github.com/ROCm/rocm-libraries/pull/9052).

**Author:** KKyang
**Merged:** 2026-07-13

## Description

> `invoke build` crashes in `_setup_msvc_env()` on a Windows machine whose active code page doesn't match what VS's tooling assumes (e.g. a JIS/Shift-JIS system locale with an English-language VS Build Tools install): an undecodable byte in `vcvarsall.bat`'s banner output aborts the `mbcs`-decoded read mid-stream, leaving `result.stdout` as `None` and crashing the following `.splitlines()` call.
