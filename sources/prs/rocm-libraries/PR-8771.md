## Description

> The hipDNN Python frontend extension (a nanobind `MODULE` library) was installing to `lib/` on Windows. CMake classifies `MODULE` libraries as `LIBRARY` artifacts on every platform, so the install was governed solely by `LIBRARY DESTINATION` and the accompanying `RUNTIME DESTINATION` never applied. That left `hipdnn_frontend_python*.pyd` separated from `hipdnn_backend.dll` (which installs to `bin/` on Windows), so the TheRock Windows Python-bindings wheel test could not locate the extension.
