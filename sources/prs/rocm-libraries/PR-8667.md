## Description

> PR #8207 ([hipblaslt] Add packed pk8 FP8 conversion) introduced the v_cvt_scalef32_pk8/sr_pk8 packed conversion path on gfx1250. Three regressions surfaced from that work, two of which break codegen/CheckASMCodeSize outright and one of which produces wrong results. This PR fixes all three so the affected gfx1250 GEMM configs pass again.
