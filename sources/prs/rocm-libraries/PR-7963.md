# fix(rocfft): generalize 2D r2c/c2r to multi-dimensional batch

Merged PR #7963 in [ROCm/rocm-libraries](https://github.com/ROCm/rocm-libraries/pull/7963).

**Author:** regan-amd
**Merged:** 2026-07-13

## Description

> Currently, an internal exception is triggered in the general multi-device code path introduced in #6691 for some single-precision real transforms of size $320^3$ of interest. This results in giving up on a parallel computation and using the fallback gather-scatter strategy instead. This PR addresses the issues responsible for triggering that internal exception and enables the general multi-device computation code path for such sizes.
