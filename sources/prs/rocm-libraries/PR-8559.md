# [CK_DSL] Reset tiled C-core build-local caches

Merged PR #8559 in [ROCm/rocm-libraries](https://github.com/ROCm/rocm-libraries/pull/8559).

**Author:** BrianHarrisonAMD
**Merged:** 2026-06-18

## Description

> This PR resets the CK DSL C-core tiled-attention build-local static caches before each gfx942/gfx950 tiled build. The reset prevents a later build in the same process from reusing `ckc_value_t*` or tile-distribution pointers allocated from a previous IRBuilder arena, and adds an in-tree host-only regression test for sequential tiled builds.
