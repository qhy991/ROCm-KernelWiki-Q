# [MIOpen] ALMIOPEN-2069 Work around missing nlohmann_json natvis file in TheRock prebuilt artifact

Merged PR #8331 in [ROCm/rocm-libraries](https://github.com/ROCm/rocm-libraries/pull/8331).

**Author:** mousdahl-amd
**Merged:** 2026-06-17

## Description

> MIOpen's standalone CMake configure fails when consuming TheRock's prebuilt `nlohmann_json` artifact because the imported target's `INTERFACE_SOURCES` references a `.natvis` debug-visualizer file that is absent from the artifact. This adds a guarded workaround that drops only the missing `.natvis` entry from the imported target, allowing configure and build to proceed. The fix is self-removing: once the upstream artifact ships the file, the entry is left untouched.
