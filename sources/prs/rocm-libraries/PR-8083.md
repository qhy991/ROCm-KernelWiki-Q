# feat(rocsparse): add rocsparse_handle_create/rocsparse_handle_destroy

**Author:** kliegeois
**Merged:** 2026-07-17

## Description

> Adds a new public API, `rocsparse_create_handle_with_stream(rocsparse_handle*, hipStream_t)`, that creates a rocSPARSE handle whose setup work runs on a user-supplied stream instead of the default (NULL) stream. This prevents handle creation from implicitly blocking work the user has already enqueued on their own streams. The existing `rocsparse_create_handle` behavior is unchanged.
