# feat(rocfft): integrate RCCL for single-node multi-GPU global transposition.

Merged PR #3042 in [ROCm/rocm-libraries](https://github.com/ROCm/rocm-libraries/pull/3042).

**Author:** af-ayala
**Merged:** 2026-07-08

## Description

> Single-node multi-GPU FFT operations in rocFFT currently rely on peer-to-peer (P2P) hipMemcpyPeerAsync calls for data transfers during global transpose operations. While P2P works well for 2-GPU configurations, performance degrades at higher GPU counts (4+) due to lack of topology awareness and suboptimal routing through the interconnect fabric.
