# [CK][CI] Make gfx1250 build compile-only

## Description

> gfx1250 has no CI hardware, so its build piggybacks on gfx90a nodes where gfx1250 binaries can be compiled but not run. The build currently fails because post-build runtime tests fire on the gfx90a node. This PR makes the gfx1250 build compile + install only.
