# fix(hipdnn): de-flake autotune strategy smoke test

Merged PR #9474 in [ROCm/rocm-libraries](https://github.com/ROCm/rocm-libraries/pull/9474).

**Author:** BrianHarrisonAMD
**Merged:** 2026-07-16

## Description

> Fixes intermittent failures of `IntegrationAutotuneStrategySmoke`. The autotune test plugin executed a host-only no-op, so the benchmark timed an empty GPU interval and `hipEventElapsedTime` could return a slightly negative value. The plugin now does real device work when benchmarked, and `computeMean` is hardened against float rounding.
