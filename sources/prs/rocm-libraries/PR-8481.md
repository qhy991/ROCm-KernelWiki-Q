# [CK DSL] conv: ML heuristic for implicit-GEMM forward

Merged PR #8481 in [ROCm/rocm-libraries](https://github.com/ROCm/rocm-libraries/pull/8481).

**Author:** cderb
**Merged:** 2026-06-18

## Description

> Adds an end-to-end ML heuristic pipeline for the CK DSL provider's implicit-GEMM convolution-forward path (fp16, gfx942/MI300X). A LightGBM model replaces the FirstFit tile selector, selecting the best `(tile_m, tile_n, tile_k, pipeline)` configuration per problem. This PR delivers the in-repo model, the offline oracle sweep tool that produced its training data, the data processing and training scripts, and a validation harness — giving the DSL provider full ownership of its heuristic lifecycle.
