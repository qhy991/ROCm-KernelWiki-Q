# docs(rfc): extend RFC 0015 engine support claims for bundle sweeps

Merged PR #9296 in [ROCm/rocm-libraries](https://github.com/ROCm/rocm-libraries/pull/9296).

**Author:** adickin-amd
**Merged:** 2026-07-16

## Description

> Extends [RFC 0015: Per-Graph Engine Support Claims](projects/hipdnn/docs/rfcs/0015_EngineSupportClaims.md) to cover the template-sweep ("bundle sweep") bundles introduced by [RFC 0011](projects/hipdnn/docs/rfcs/0011_GoldenReferenceValidation.md), so support claims can attach per sweep case rather than only per single-graph bundle. This unblocks pinning engine-support contracts for sweep-defined graphs, which the integration-test suite already exercises today.
