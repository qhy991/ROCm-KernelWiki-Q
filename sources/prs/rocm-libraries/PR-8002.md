# [stinkytofu] Rewrite wait-count insertion as SSA def-use dataflow with per-counter FIFO modeling

Merged PR #8002 in [ROCm/rocm-libraries](https://github.com/ROCm/rocm-libraries/pull/8002).

**Author:** pschang-phy
**Merged:** 2026-06-16

## Description

> The previous wait-count insertion relied on ad-hoc token-matching heuristics that could both **under-count** (a consumer reads an async result before its producer retired — a correctness hazard) and **over-drain** (redundant `s_wait_*` that serialize otherwise-overlapping memory traffic). It also did not model SMRD scalar loads, so `s_load_*` results could be consumed without an `s_wait_kmcnt`.
